# ฐานข้อมูลจุดเก็บตัวอย่าง (Field Sample Database)

โปรแกรมบันทึก **จุด / พื้นที่ เก็บตัวอย่างสิ่งแวดล้อม** บนแผนที่ภาพถ่ายดาวเทียมแบบ Google Earth
ต่างจาก Google Earth Pro ตรงที่ข้อมูลทั้งหมดเก็บเป็น **ฐานข้อมูล (SQLite)** ทำให้:

- **แก้ไข/อัปเดตได้ และเก็บประวัติทุกครั้ง** ว่าใครแก้อะไร เมื่อไร ค่าเก่าเป็นเท่าไร
  และ **ย้อนกลับเป็นข้อมูลเก่า** ได้ (การลบก็กู้คืนได้ ไม่มีข้อมูลหายถาวร)
- เก็บ **ตัวอย่างหลายครั้งต่อจุด** แต่ละครั้งมีวันที่ ประเภทตัวอย่าง (ดิน, ดินผิวหน้า, ตะกอนดิน,
  น้ำผิวดิน, น้ำใต้ดิน, น้ำทิ้ง, อากาศ, อื่นๆ) ความลึก ผู้เก็บ แล็บ เลขที่รายงาน
  และ **ผลวิเคราะห์สาร** กี่พารามิเตอร์ก็ได้ (รองรับค่าแบบ `<0.01`, `ND`)
- **แนบรูปถ่าย** ต่อจุด (ผูกกับตัวอย่างครั้งไหนก็ได้) — ย่อขนาดอัตโนมัติก่อนบันทึก
- **เทียบค่ามาตรฐานอัตโนมัติ** ไฮไลต์สีแดงเมื่อเกิน และหมุดบนแผนที่เป็นสีแดง
- **ค้นหา / กรอง / เรียงลำดับ** ทั้งรายการจุด และตารางผลวิเคราะห์ทั้งหมด (ตามสาร, ประเภท,
  โครงการ, ช่วงวันที่, เฉพาะที่เกินมาตรฐาน) แล้วส่งออกเป็น CSV เปิดใน Excel ได้
- **นำเข้าไฟล์ .kml / .kmz จาก Google Earth Pro** ที่มีอยู่แล้วได้ทันที (หมุด เส้น และพื้นที่ polygon
  ชื่อโฟลเดอร์ใน Earth จะกลายเป็น "ประเภทจุด" และ "โครงการ") และ **ส่งออกกลับเป็น .kml**
  เพื่อเปิดดูใน Google Earth ได้ (ในหมุดมีตารางผลวิเคราะห์ให้ด้วย)
- พิกัดแสดงทั้ง **Lat/Long และ UTM (โซน 47/48)** กรอกแบบไหนก็ได้ ระบบแปลงให้

## วิธีเปิดใช้งาน

ต้องมี **Python 3.8 ขึ้นไป** เท่านั้น ไม่ต้องติดตั้งอะไรเพิ่ม (ไม่ต้อง pip install)
— Windows ดาวน์โหลดจาก <https://www.python.org/downloads/> ตอนติดตั้งให้ติ๊ก **"Add python.exe to PATH"**

| ระบบ | วิธีเปิด |
|---|---|
| Windows | ดับเบิลคลิก `start-windows.bat` |
| Mac / Linux | ดับเบิลคลิก `start-mac-linux.sh` หรือพิมพ์ `python3 app.py` |

โปรแกรมจะเปิดเบราว์เซอร์ไปที่ <http://localhost:8765/> ให้อัตโนมัติ — **อย่าปิดหน้าต่างดำ (console)
ระหว่างใช้งาน** ปิดหน้าต่างนั้นเมื่อเลิกใช้

ต้องต่ออินเทอร์เน็ตเพื่อโหลดภาพแผนที่ดาวเทียม (ข้อมูลของคุณไม่ได้ส่งออกไปไหน อยู่ในเครื่องทั้งหมด)

### อยากลองดูก่อนด้วยข้อมูลตัวอย่าง

```bash
python3 seed_demo.py
```

```bash
python3 app.py --db data/demo.db
```

(ข้อมูลใน demo เป็นค่าสมมติทั้งหมด ไม่ใช่ผลตรวจจริง)

## การใช้งานหลัก

1. ใส่ **ชื่อผู้บันทึก** มุมขวาบนก่อน (ชื่อนี้จะไปอยู่ในประวัติการแก้ไขทุกครั้ง)
2. เพิ่มจุด: กด **📍 เพิ่มจุด** แล้วคลิกบนแผนที่ / **⬠ วาดพื้นที่** คลิกทีละมุมแล้วดับเบิลคลิกจบ /
   **⌨ ป้อนพิกัด** พิมพ์ Lat/Long หรือ UTM เอง — หรือ **นำเข้า KML/KMZ** จาก Google Earth
3. คลิกจุด → แผงรายละเอียดด้านขวา: แก้ไขข้อมูล, ย้ายหมุด, วาดขอบเขตพื้นที่, **+ เพิ่มรูป**,
   **+ เพิ่มตัวอย่าง** (กรอกผลวิเคราะห์ได้หลายแถว, ปุ่ม "เติมพารามิเตอร์จากค่ามาตรฐาน",
   หรือ "วางจาก Excel" คัดลอก 3 คอลัมน์ พารามิเตอร์/ค่า/หน่วย มาวางได้เลย)
4. แท็บ **ผลวิเคราะห์**: ตารางรวมทุกผล คลิกหัวคอลัมน์เพื่อเรียง คลิกแถวเพื่อไปที่จุดนั้นบนแผนที่
5. แท็บ **ประวัติ**: ดูทุกการเปลี่ยนแปลง (ค่าเก่า → ค่าใหม่) กด **↶ ย้อนกลับ** เพื่อคืนค่าก่อนแก้
   (ดูประวัติเฉพาะจุดได้จากแผงรายละเอียด → "ประวัติการแก้ไข" และเฉพาะตัวอย่างได้จากปุ่ม 🕘)
6. แท็บ **ค่ามาตรฐาน**: ใส่ค่าต่ำสุด/สูงสุดของแต่ละพารามิเตอร์ต่อประเภทตัวอย่าง
   (เว้นประเภทว่าง = ใช้กับทุกประเภท) — **ต้องใส่ค่าตามประกาศฉบับจริงเอง**

ช่องค้นหาในแท็บจุด พิมพ์พิกัด เช่น `13.84, 101.91` แล้วกด Enter เพื่อบินไปตำแหน่งนั้นได้

### นำเข้าผลแล็บจาก Excel (CSV)

บันทึก Excel เป็น **CSV UTF-8** โดยมีหัวคอลัมน์ (1 แถว = 1 พารามิเตอร์):

```
site_code,site_name,lat,lng,project,sample_code,sample_date,media,depth,sampler,lab,parameter,value,unit
SW-01,คลองท้ายโรงงาน,13.7301,101.5231,โครงการ A,SW-01-1,2026-05-27,surface_water,,สมชาย,แล็บ X,Pb,0.012,mg/L
```

- รหัสจุดที่มีอยู่แล้ว → เพิ่มตัวอย่างเข้าจุดเดิม; ยังไม่มี → ต้องมี lat,lng เพื่อสร้างจุดใหม่
- แถวที่ จุด/รหัสตัวอย่าง/วันที่/ประเภท/ความลึก ตรงกัน รวมเป็นตัวอย่างเดียวกัน
- `media` ใช้ `soil`, `surface_soil`, `sediment`, `surface_water`, `groundwater`, `wastewater`,
  `air`, `other` หรือพิมพ์ชื่อไทย (ดิน, ตะกอนดิน, น้ำใต้ดิน ฯลฯ) ก็ได้
- วันที่ใช้ปี **ค.ศ.** รูปแบบ `ปปปป-ดด-วว`

## ใช้ร่วมกันหลายคน (ในสำนักงาน)

เปิดโปรแกรมบนเครื่องกลางเครื่องเดียวด้วย

```bash
python3 app.py --host 0.0.0.0
```

แล้วเครื่องอื่นในวง LAN / Wi-Fi เดียวกันเปิด `http://<IP เครื่องกลาง>:8765/` (มือถือก็ได้ —
ถ่ายรูปหน้างานแล้วอัปโหลดเข้าจุดได้เลย) ทุกคนเห็นข้อมูลชุดเดียวกัน
**ข้อควรทราบ**: ยังไม่มีระบบรหัสผ่าน ใครเข้าถึงเครือข่ายนั้นได้ก็แก้ข้อมูลได้
(แต่ทุกการแก้มีประวัติและย้อนกลับได้) — อย่าเปิดพอร์ตนี้ออกอินเทอร์เน็ตสาธารณะ

## สำรองข้อมูล

ข้อมูลทั้งหมด (รวมรูป) อยู่ในไฟล์เดียว: `data/fielddata.db`

- เมนู **⬇ ส่งออก → สำรองฐานข้อมูลทั้งไฟล์** ได้ไฟล์ .db (กดได้ระหว่างใช้งาน)
- กู้คืน: ปิดโปรแกรม แล้วนำไฟล์ .db ที่สำรองไว้มาวางแทน `data/fielddata.db`
  (หรือเปิดไฟล์นั้นตรงๆ ด้วย `python3 app.py --db ไฟล์สำรอง.db`)
- ไฟล์ .db เปิดดูด้วยโปรแกรมอื่นได้ เช่น [DB Browser for SQLite](https://sqlitebrowser.org/) หรือ QGIS

## โครงสร้างข้อมูล

| ตาราง | เก็บอะไร |
|---|---|
| `sites` | จุด/พื้นที่: รหัส ชื่อ ประเภทจุด โครงการ จังหวัด ที่ตั้ง รายละเอียด lat/lng รูปร่าง (GeoJSON) |
| `samples` | การเก็บตัวอย่างแต่ละครั้ง: จุด ประเภทตัวอย่าง วันที่ ความลึก ผู้เก็บ แล็บ เลขที่รายงาน |
| `results` | ผลวิเคราะห์: ตัวอย่าง พารามิเตอร์ ค่า (ข้อความดิบ + ตัวเลข) หน่วย วิธีวิเคราะห์ |
| `photos` | รูปถ่าย (เก็บในฐานข้อมูล) + รูปย่อ คำบรรยาย วันที่ถ่าย |
| `standards` | ค่ามาตรฐาน ต่อประเภทตัวอย่าง + พารามิเตอร์ |
| `history` | ประวัติทุกการเปลี่ยนแปลง: เวลา ผู้แก้ การกระทำ ข้อมูลก่อน/หลัง (JSON) |

การลบเป็นแบบ "ซ่อน" (soft delete) ข้อมูลยังอยู่และกู้คืนได้จากประวัติ

## สำหรับนักพัฒนา

- `app.py` — เซิร์ฟเวอร์ + API (Python มาตรฐานล้วน: `http.server`, `sqlite3`)
- `static/` — หน้าเว็บ (Leaflet + JavaScript ธรรมดา ไม่ต้อง build)
- ทดสอบ: `python3 -m unittest test_app.py`
