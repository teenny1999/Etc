# บ่อน้ำบาดาลรอบจุดประเมิน (Groundwater Radius Report)

**v0.1** — เครื่องมือช่วยตอบคำถาม "รอบๆ จุดที่จะประเมิน (เช่น พื้นที่โรงงาน หรือจุดที่สงสัยว่ามี
การลักลอบปล่อยมลพิษ) ในแต่ละรัศมี (กม.) มีบ่อน้ำบาดาลอะไรบ้าง ห่างเท่าไหร่" โดยดึงข้อมูลจริงจาก
ระบบสืบค้นบ่อน้ำบาดาลของกรมทรัพยากรน้ำบาดาล (DGR):
http://app.dgr.go.th/newpasutara/xml/search.php

## ทำงานยังไง

เว็บต้นทาง**ไม่มี**ช่องค้นหาแบบ "รัศมีรอบพิกัด" ให้โดยตรง — รองรับแค่ค้นตามจังหวัด/อำเภอ/ตำบล
และตัวกรองอำเภอ/ตำบลของเว็บ (`ddlProvince`/`ddlAmphur`) มีบั๊กฝั่งเซิร์ฟเวอร์ (ส่งไปแล้วได้ผลลัพธ์
0 แถวเสมอ ทดสอบแล้ว) เครื่องมือนี้เลยทำงาน 3 ขั้น:

1. ดึงรายชื่อบ่อ **ทั้งจังหวัด** จากตาราง `tshow.php` (มีชื่อตำบล/อำเภอกำกับมาด้วยอยู่แล้ว)
2. กรองเฉพาะบ่อในอำเภอ/ตำบลที่สนใจด้วยข้อความ (ฝั่งเราเอง แก้บั๊กข้อ 1) เพื่อลดจำนวนก่อนดึงพิกัด
3. ไล่เปิดหน้ารายละเอียดของแต่ละบ่อที่เหลือ (`tmapdetail2.php`) เพื่อดึงพิกัด lat/lon จริง แล้ว
   คำนวณระยะห่างแบบเส้นตรง (haversine) จากจุดศูนย์กลางที่กำหนด และจัดกลุ่มเข้าวงรัศมีที่ตั้งไว้

**ข้อควรทราบ**: ขั้นตอน 3 ต้องเปิดหนึ่งหน้าเว็บต่อหนึ่งบ่อ — ถ้าไม่กรองอำเภอ/ตำบลก่อน จังหวัดใหญ่ๆ
อาจมีเป็นพันบ่อ (ทดสอบแล้ว: เชียงใหม่ ~2,300 บ่อ, นครราชสีมา ~2,900 บ่อ) จะช้ามากและเป็นการเรียก
เว็บของกรมฯ ถี่เกินสมควร — **แนะนำให้ระบุ `--amphoe-name`/`--tambon-name` เสมอ** ยกเว้นจุดที่จะ
ประเมินอยู่ใกล้รอยต่อหลายอำเภอจริงๆ

## ใช้งาน

ต้องมี Python 3 (ไม่ต้องติดตั้งไลบรารีเพิ่ม ใช้แต่ standard library)

```bash
# 1) ดูรหัสจังหวัด
python3 fetch_dgr_wells.py --list-provinces

# 2) ดูชื่ออำเภอที่สะกดถูกต้องตามฐานข้อมูล (ใส่รหัสจังหวัดจากข้อ 1)
python3 fetch_dgr_wells.py --list-amphoes --province 1

# 3) (ถ้าต้องการกรองละเอียดถึงตำบล) ดูรหัส/ชื่อตำบล — ใส่รหัสอำเภอ (ไม่ใช่ชื่อ) จาก pajax
python3 fetch_dgr_wells.py --list-tambons --amphoe 1001

# 4) ดึงข้อมูลบ่อรอบจุดที่จะประเมิน แบ่งวงรัศมี 1/3/5/10 กม.
python3 fetch_dgr_wells.py \
  --province 1 --amphoe-name คลองสามวา \
  --center-lat 13.8408 --center-lon 100.7414 \
  --site-label "พื้นที่โรงงาน A" \
  --radii 1,3,5,10 \
  --out-json out/wells.json --out-html out/report.html
```

เปิดไฟล์ `out/report.html` ด้วยเบราว์เซอร์ — จะเห็นแผนที่ (Leaflet) มีหมุดจุดที่ประเมิน วงรัศมี
ตามที่กำหนด และจุดบ่อน้ำบาดาลแต่ละบ่อ (สีตามวงที่อยู่) พร้อมตารางรายชื่อบ่อเรียงตามระยะทาง
คลิกแถวในตารางเพื่อซูมแผนที่ไปที่บ่อนั้น หรือคลิกหัวคอลัมน์เพื่อเรียงลำดับใหม่

### พารามิเตอร์หลัก

| flag | ความหมาย |
|---|---|
| `--province` | รหัสจังหวัด (`ddlGeo`) จาก `--list-provinces` |
| `--amphoe-name` / `--tambon-name` | กรองชื่ออำเภอ/ตำบล (จับคู่แบบ substring) ก่อนไปดึงพิกัด |
| `--center-lat` / `--center-lon` | พิกัดจุดที่จะประเมิน (เช่น พื้นที่โรงงาน/จุดลักลอบ) |
| `--site-label` | ชื่อจุดอ้างอิงที่จะแสดงบนแผนที่/รายงาน |
| `--radii` | รายการรัศมี หน่วยกิโลเมตร คั่นด้วย `,` (ค่าเริ่มต้น `1,3,5,10`) |
| `--max-radius-km` | ตัดบ่อที่ไกลกว่านี้ทิ้ง (ค่าเริ่มต้น = วงรัศมีนอกสุด) |
| `--max-wells` | เพดานจำนวนบ่อที่จะไล่ดึงพิกัด กันเผลอโหลดหนักเกินไป (ค่าเริ่มต้น 2000) |
| `--out-json` / `--out-html` | ที่เก็บไฟล์ผลลัพธ์ |

ไฟล์ JSON ที่ได้ (`--out-json`) เก็บพิกัด/ระยะทาง/ความลึก/ปริมาณน้ำของแต่ละบ่อไว้ครบ เอาไป
ประมวลผลต่อ (เช่น เปิดใน Excel, ใช้กับ GIS อื่น) ได้โดยไม่ต้องรันสคริปต์ใหม่

## ข้อจำกัด / สิ่งที่ควรรู้ก่อนใช้จริง

- ข้อมูลจากเว็บ DGR **แสดงเฉพาะบ่อที่สภาพ "ใช้การได้" และสภาพน้ำ "จืด" เท่านั้น** (ตามหมายเหตุ
  ของหน้าเว็บต้นทาง) — บ่อที่ทิ้งร้าง หรือน้ำเค็ม/กร่อยจะไม่ปรากฏในผลลัพธ์
- ระยะทางที่คำนวณเป็น**ระยะเส้นตรง (straight-line / haversine)** ไม่ใช่ระยะตามเส้นทางถนน และ
  ไม่ได้คำนึงถึงทิศทางการไหลของน้ำใต้ดินหรือชั้นหินอุ้มน้ำ — ใช้เป็นข้อมูลเบื้องต้นสำหรับกะระยะ
  เท่านั้น การประเมินผลกระทบจริงจัง (เช่น ทิศทาง gradient ของน้ำใต้ดิน) ต้องใช้ผู้เชี่ยวชาญ
  water resource/hydrogeology ร่วมพิจารณาข้อมูลชั้นดิน/ชั้นหินอุ้มน้ำเพิ่มเติม
- เป็นการดึงข้อมูลจากเว็บสาธารณะของหน่วยงานรัฐ (ไม่ได้ผ่าน API ทางการ) — ใช้ตามความเหมาะสม
  ไม่ควรตั้ง `--max-workers`/`--max-wells` สูงเกินจำเป็นเพื่อไม่ให้เป็นภาระเซิร์ฟเวอร์ของกรมฯ
- ถ้าเว็บต้นทางเปลี่ยนโครงสร้าง HTML สคริปต์นี้จะดึงข้อมูลไม่ได้ (ต้องแก้ regex ในสคริปต์ตาม)

```
report_template.html   เทมเพลตหน้าแผนที่ (แทรกข้อมูล JSON แล้ว build เป็น out/report.html)
out/                   ผลลัพธ์ที่สร้างจากการรัน (ไม่ commit เข้า git — ดู .gitignore)
```
