# Project brief: ตรวจจับบ่อขยะลักลอบทิ้งจากภาพดาวเทียม (ประเทศไทย)

เอกสารนี้ใช้ส่งต่องานให้ Claude Code อ่านให้จบก่อนเริ่ม แล้วทำตามลำดับ Phase
ช่องที่เขียนว่า `[ต้องกรอก]` คือข้อมูลที่ผู้ใช้ต้องให้ ถ้ายังว่างให้ถามผู้ใช้ก่อน อย่าเดาเอง

## 1. เป้าหมาย

สร้างระบบที่ใช้ภาพ Sentinel-2 ชี้เป้าบ่อขยะและกองขยะกลางแจ้งในไทย โดยเน้นจุดที่
**เกิดใหม่** และ **ไม่อยู่ในรายชื่อสถานที่กำจัดที่ได้รับอนุญาต** เพื่อส่งให้เจ้าหน้าที่ตรวจสอบต่อ

- ระบบทำหน้าที่ "ชี้เป้า" (tip and cue) การตัดสินว่าลักลอบจริงหรือไม่เป็นหน้าที่ของคน
- เป้าหมายคือกองขยะทั่วไป ไม่ได้จำกัดเฉพาะพลาสติก
- ผลลัพธ์สุดท้าย: รายการจุดต้องสงสัยพร้อมพิกัด วันที่เริ่มพบ ขนาด และระยะถึงแหล่งน้ำ

## 4. สภาพแวดล้อม

- ผู้ใช้รัน Claude Code บน Windows (CMD) คำสั่งและ path ต้องใช้กับ Windows ได้
- ก่อนเลือก framework ให้ตรวจว่าเครื่องใช้ GPU ได้จริงหรือไม่ ถ้าไม่ได้ ให้เสนอทางเลือก
  (เช่น WSL2 หรือรันส่วนฝึกโมเดลบน cloud) พร้อมข้อดีข้อเสีย แล้วให้ผู้ใช้เลือก
- ใช้ Python virtual environment แยกของโปรเจกต์ และบันทึก dependency ใน `requirements.txt`

## 5. วิธีการตามงานวิจัย (ค่าพารามิเตอร์ต้นฉบับ)

### 5.1 ข้อมูลภาพ
- Sentinel-2 L1C (Top-of-Atmosphere) ใช้ 12 แบนด์: B1–B9, B8A, B11, B12
- กรองเมฆและเงาเมฆ แล้วรวมภาพช่วง 3 เดือนด้วย **ค่าต่ำสุด** ของแต่ละพิกเซล (ตัดหมอกและเมฆบาง)
- จับคู่ภาพรวมกับภาพรวมของจุดเดียวกันที่ห่างกัน 6 เดือน
- normalize แยกรายแบนด์จากชุดข้อมูลฝึก
- ตัวอย่างฝึก: patch 480×480 ม. รอบจุดศูนย์กลางแต่ละแห่ง
- พิกเซลกลุ่มขยะ: ตัดพิกเซลที่ NDVI > 0.4 ออก
- จุดที่ไม่ใช่ขยะ: เลือกพื้นที่ที่สเปกตรัมคล้ายขยะ (ดินเปล่า เขตเมือง โรงเรือนพลาสติก)

### 5.2 Pixel classifier
- input shape (12, 2): 12 แบนด์ × 2 ช่วงเวลา
- Conv2D 16 filters (3,2) ReLU → Conv2D 32 filters (3,2) ReLU → Flatten
  → Dense 32 ReLU → Dense 32 ReLU → Dropout 0.1 → Dense 32 ReLU → Dense 2 Softmax
- Adam, learning rate 0.001, batch size 128, Glorot uniform

### 5.3 Patch classifier
- input shape (28, 28, 24): 28×28 พิกเซล, 12 แบนด์ × 2 ช่วงเวลาต่อกันตามแกน channel
- Convolutional block ×3: [Conv2D 32 filters (5,5) LeakyReLU + BatchNorm] ×3 → MaxPool → BatchNorm
- Dense block ×2: Dropout 0.5 → Dense 512 ELU → BatchNorm
- Dropout 0.5 → Dense 2 Softmax
- augmentation: reflection, rotation
- ต้นฉบับฝึกแบบ semi-supervised distillation (teacher 32 ตัว + RBF SVM + pixel classifier
  สร้าง soft label ให้ student) **ในรอบแรกให้ฝึกแบบ supervised ธรรมดาก่อน** แล้วค่อยเพิ่ม
  distillation เมื่อ baseline ทำงานแล้ว

### 5.4 ตรวจหาจุดต้องสงสัย
- pixel classifier ประเมินทุกพิกเซล → heatmap; patch classifier เลื่อนด้วย stride 8 พิกเซล
- เฉลี่ยผลหลายช่วงเวลาเพื่อลด noise
- threshold heatmap แล้วใช้ `skimage.feature.blob_doh` หาจุดศูนย์กลาง
- รับเป็น candidate เมื่อค่า patch classifier ที่ตำแหน่งนั้นเกิน threshold

| โหมด | Pixel threshold | min_sigma | Patch threshold |
|---|---|---|---|
| Low | 0.9 | 5.0 | 0.6 |
| Medium | 0.6 | 5.0 | 0.6 |
| High | 0.6 | 3.5 | 0.3 |

ผลในอินโดนีเซีย: recall 80% ที่โหมด High, 40% ที่โหมด Low/Medium

### 5.5 ขอบเขตกองขยะรายเดือน
- รัน pixel classifier กับภาพรวมรายเดือน
- สร้าง mask จาก rolling median ของ 8 ช่วงเวลาถัดไป แล้ว threshold
- ลากเส้นขอบ (contour) รอบผลลัพธ์ เป็น footprint รายเดือน

### 5.6 ข้อมูลประกอบ
- ระยะถึงแหล่งน้ำที่ใกล้ที่สุดจาก OpenStreetMap ภายในรัศมี 5 กม.
- ความสูงและความลาดชัน (SRTM), ประชากรโดยรอบ (WorldPop)

## 6. สิ่งที่ต้องปรับจากงานวิจัยสำหรับกรณีลักลอบทิ้ง

1. **หาจุดเกิดใหม่:** คำนวณวันที่เริ่มพบสัญญาณขยะของแต่ละจุดจากอนุกรมเวลา
   และแจ้งเตือนจุดที่เพิ่งปรากฏในพื้นที่ที่เคยว่าง
2. **ตัดจุดถูกกฎหมาย:** ซ้อนกับรายชื่อสถานที่ที่ได้รับอนุญาต (กำหนดระยะ buffer ร่วมกับผู้ใช้)
   จุดที่ไม่อยู่ในรายชื่อคือจุดต้องตรวจสอบ
3. **ไม่คัดทิ้งเพราะภาพยืนยันเก่า:** งานวิจัยคัดจุดที่ไม่เห็นใน Google Earth ออก
   ซึ่งทำให้กองขยะใหม่หลุด ในโปรเจกต์นี้ให้เก็บไว้เป็นสถานะ "รอตรวจสอบ" แทน
4. **ฝึกเพิ่มด้วยข้อมูลไทย:** โมเดลเดิมฝึกจากขยะชุมชนในอินโดนีเซียเป็นหลัก

## 7. ลำดับงาน

**Phase 0: สำรวจและตั้งค่า**
- clone repo ต้นฉบับ อ่านโครงสร้าง ตรวจโฟลเดอร์ `models/` ว่ามีโมเดลอะไร รูปแบบไฟล์ใด
- ลองโหลดโมเดลเดิม รายงานผลตามจริงว่าโหลดได้หรือไม่ และ input/normalization ที่ต้องใช้
- ตรวจ dataset ID และวิธีกรองเมฆของแหล่งภาพที่เลือก จากเอกสารปัจจุบัน (อย่าใช้จากความจำ)
- ส่งมอบ: สรุปสั้นว่าอะไรใช้ต่อได้ อะไรต้องเขียนใหม่

**Phase 1: ท่อข้อมูลภาพ**
- เขียนโค้ดดึงภาพ กรองเมฆ รวมภาพ 3 เดือน และจับคู่ 6 เดือน สำหรับพื้นที่นำร่อง
- ทดสอบกับพื้นที่เล็ก (ประมาณ 10×10 กม.) ก่อนขยาย
- ส่งมอบ: ภาพรวมตัวอย่างที่เปิดดูได้ และสคริปต์ที่รันซ้ำได้

**Phase 2: Baseline ด้วยโมเดลเดิม** (ข้ามได้ถ้า Phase 0 พบว่าโมเดลเดิมใช้ไม่ได้)
- รันโมเดลเดิมบนพื้นที่นำร่อง แล้ววัด recall เทียบกับพิกัดบ่อขยะที่ยืนยันแล้ว
- ส่งมอบ: ตัวเลข recall และจำนวน candidate ต่อโหมดความไว

**Phase 3: ฝึกด้วยข้อมูลไทย**
- สร้างชุดข้อมูลฝึกจากพิกัดของผู้ใช้ แยกชุดทดสอบตาม **สถานที่** (ห้ามให้ที่เดียวกันอยู่ทั้งสองชุด)
- ฝึก pixel และ patch classifier รายงาน precision, recall, F1 บนชุดทดสอบ
- วนรอบ bootstrapping: นำจุดที่ผู้ใช้ยืนยันและจุดที่ทายผิดกลับมาฝึกเพิ่ม

**Phase 4: ชี้เป้าจุดลักลอบ**
- ตรวจหา candidate ทั้งพื้นที่นำร่อง คำนวณวันที่เริ่มพบ ตัดจุดที่ได้รับอนุญาต เติมข้อมูลประกอบ
- ส่งมอบ: `candidates.geojson` และ `candidates.csv` มีคอลัมน์
  `id, lat, lon, first_seen, area_ha, score, dist_water_m, in_permitted_list, status`

**Phase 5: เครื่องมือตรวจยืนยัน**
- หน้าเว็บแบบไฟล์เดียวที่แสดง candidate ทีละจุด: ภาพ Sentinel-2 ก่อนและหลัง กราฟสัญญาณตามเวลา
  ลิงก์เปิดพิกัดในแผนที่ภายนอก และปุ่มบันทึกผล (ยืนยัน / ไม่ใช่ / ต้องลงพื้นที่) ลง CSV

**Phase 6: ติดตามต่อเนื่อง**
- สคริปต์รันรายเดือน: อัปเดต footprint ของจุดเดิม และรายงานจุดใหม่

## 8. กติกาการทำงาน

- ทำทีละ Phase จบแต่ละ Phase ให้สรุปผลและรอผู้ใช้ยืนยันก่อนไปต่อ
- เริ่มจากพื้นที่เล็กเสมอ ถามผู้ใช้ก่อนดาวน์โหลดข้อมูลขนาดใหญ่หรือใช้บริการที่มีค่าใช้จ่าย
- ห้ามสร้างพิกัดหรือ label ขึ้นเอง ใช้เฉพาะข้อมูลที่ผู้ใช้ให้หรือแหล่งที่อ้างอิงได้
- รายงานตัวเลขตามจริง ถ้าผลไม่ดีหรือขั้นไหนทำไม่สำเร็จให้บอกตรง ๆ พร้อมสาเหตุ
- ห้ามเก็บ credential หรือ API key ในโค้ดหรือ repo ใช้ environment variable
- ข้อมูลพิกัดของหน่วยงานถือเป็นข้อมูลภายใน ห้ามอัปโหลดไปบริการภายนอกโดยไม่ถามผู้ใช้
- เขียนคำอธิบายและรายงานเป็นภาษาไทย ชื่อตัวแปรและโค้ดเป็นภาษาอังกฤษ

## 9. ข้อจำกัดที่ต้องบอกผู้ใช้ในรายงานทุกครั้ง

- ขนาดเล็กสุดที่ตรวจจับได้ประมาณ 30×30 ม. (0.1 เฮกตาร์)
- เห็นเฉพาะกองขยะกลางแจ้ง ไม่เห็นของที่อยู่ในอาคาร ฝังกลบแล้ว หรือมีพืชคลุม
- การรวมภาพ 3 เดือนและเมฆหน้าฝนทำให้รู้ช้ากว่าเหตุการณ์จริงหลายสัปดาห์ถึงหลายเดือน
- ในงานวิจัย คนยืนยันได้เฉลี่ย 53% ของจุดที่โมเดลเสนอ จุดต้องสงสัยจึงยังไม่ใช่ข้อเท็จจริง
- โมเดลเดิมฝึกจากขยะชุมชน ยังไม่เคยทดสอบกับกากอุตสาหกรรมหรือของเสียอันตราย
