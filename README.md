# ระบบติดตามตัวอย่างสิ่งแวดล้อม (Environmental Sample Dashboard)

**v0.1 alpha** — สำหรับทดสอบแนวคิด ยังไม่ใช่เวอร์ชันใช้งานจริง

Dashboard แผนที่ + ตารางผลตรวจ ดิน/น้ำ/อากาศ ที่ดึงข้อมูลสดจาก Google Sheets
แทนการทำแผนที่ใน Google Earth Pro ทีละครั้ง

## ทดสอบทันที (ไม่ต้องตั้งค่าอะไร)

เปิดไฟล์ `dashboard/index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิก หรือ
ลาก drop ใส่เบราว์เซอร์) ระบบจะโหลด **ข้อมูลตัวอย่าง (demo)** ให้ดูการทำงานทันที
— แผนที่, จุดสีเขียว/แดงตามผ่าน-ไม่ผ่านมาตรฐาน, ตารางผลตรวจ, ตัวกรอง

## เชื่อมกับ Google Sheets จริงของคุณ

### 1. สร้าง Google Sheet

สร้าง Google Sheet ใหม่ 1 ไฟล์ แล้วสร้างชีท (tab) ทั้ง 5 ชื่อให้ตรงตามนี้เป๊ะๆ
(ตัวพิมพ์เล็ก-ใหญ่และเครื่องหมาย `_` มีผล):

| ชื่อชีท | เก็บอะไร |
|---|---|
| `Sites` | จุดเก็บตัวอย่าง + พิกัด |
| `Soil_Results` | ผลตรวจดิน |
| `Water_Results` | ผลตรวจน้ำ |
| `Air_Results` | ผลตรวจอากาศ |
| `Standards` | ค่ามาตรฐานอ้างอิงต่อพารามิเตอร์ |

ในชีท `Sites` คอลัมน์ `type` ใส่ได้ 4 ค่า: `water`, `soil`, `air` (จุดเก็บตัวอย่าง)
หรือ `source` (จุดแหล่งกำเนิด/จุดอ้างอิง เช่น ตำแหน่งโรงงาน — ไม่มีผลตรวจของตัวเอง แต่ใช้เป็น
จุดอ้างอิงคำนวณระยะห่าง) ดูตัวอย่างแถว `source` ใน `Sites.csv`

คอลัมน์ `province` (จังหวัด) และ `case_type` (กรณี เช่น "ร้องเรียน", "ตรวจติดตามตามแผน")
เป็นข้อความอิสระ ไม่ได้กำหนดค่าตายตัว — ใส่อะไรก็ได้ ระบบจะดึงค่าที่มีจริงในข้อมูลมาสร้าง
ตัวกรอง "จังหวัด" และ "กรณี" ให้อัตโนมัติ (เว้นว่างได้ถ้าไม่ต้องการใช้)

คอลัมน์ `standard_set` ใน `Sites` และ `Standards` ใช้สำหรับกรณีที่ต้องเทียบมาตรฐานคนละชุด
ต่อจุด (เช่น น้ำผิวดินประเภท 3 vs ประเภท 5) — เว้นว่างในชีท `Standards` หมายถึง "ชุดเริ่มต้น/
ทั่วไป" ที่ใช้กับทุกจุดที่ไม่ได้ระบุ `standard_set` ของตัวเอง ถ้าจุดไหนใน `Sites` ใส่ชื่อชุด
มาตรฐานไว้ (เช่น "น้ำผิวดินประเภท 3") ระบบจะใช้ค่าจากชุดนั้นก่อน แล้วค่อย fallback ไปใช้ชุด
เริ่มต้นสำหรับพารามิเตอร์ที่ชุดนั้นไม่ได้ระบุไว้ — ดูตัวอย่างการใช้งานในข้อมูล demo (จุด S-001
ใช้ชุด "เข้มงวด (ตัวอย่าง)" ที่บังคับ BOD เข้มกว่าชุดทั่วไป)

หัวคอลัมน์ (row แรก) ของแต่ละชีทต้องตรงกับไฟล์ตัวอย่างในโฟลเดอร์
[`sheets-template/`](./sheets-template) ทุกตัวอักษร (เป็นภาษาอังกฤษ เพื่อให้โค้ดอ่านค่าได้)
— เปิดไฟล์ `.csv` ในโฟลเดอร์นั้นแล้ว import หรือ copy-paste ลงในแต่ละชีทได้เลย

**สำคัญ**: ค่าตัวอย่างในชีท `Standards` เป็น**ค่าสมมติเพื่อทดสอบระบบเท่านั้น**
ยังไม่ได้ตรวจสอบกับประกาศกระทรวงฯ ฉบับจริง — **ต้องแทนที่ด้วยค่ามาตรฐานจริงก่อนใช้งานจริง**

### 2. เปิดสิทธิ์แชร์ให้ dashboard อ่านได้

`แชร์` (Share) → เปลี่ยนเป็น **"ทุกคนที่มีลิงก์" (Anyone with the link) → ผู้ดู (Viewer)**

ข้อควรทราบ: แบบนี้คือใครมีลิงก์/Sheet ID ก็ดูข้อมูลได้ (ไม่ใช่ private แบบต้อง login)
ถ้าข้อมูลอ่อนไหวเกินกว่าจะเปิดแบบนี้ได้ ต้องแจ้งไว้ก่อน จะได้ออกแบบระบบ auth เพิ่มในเวอร์ชันถัดไป

### 3. เอา Sheet ID ไปใส่ใน dashboard

Sheet ID คือส่วนที่อยู่ระหว่าง `/d/` กับ `/edit` ใน URL ของ Google Sheet เช่น

```
https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/edit
                                        ^^^^^^^^^^^^^^^^^^^^^^^^^^^ นี่คือ Sheet ID
```

เปิด `dashboard/index.html` → วาง Sheet ID ในช่องด้านบน → กด "โหลดข้อมูล"
(ระบบจะจำไว้ใน browser ให้ ไม่ต้องวางซ้ำทุกครั้ง)

### 4. (แนะนำ) ทำ Google Form สำหรับกรอกข้อมูลหน้างาน

สร้าง Google Form แยก 3 ชุด (ดิน / น้ำ / อากาศ) โดยตั้งคำถามให้ตรงกับหัวคอลัมน์ใน
`sheets-template/*.csv` ของประเภทนั้น แล้วในขั้นตอนสร้าง Form เลือก
**"ตอบกลับ" (Responses) → เชื่อมไปยัง Google Sheet ที่สร้างไว้ในข้อ 1** (เลือกชีทเดิม
ไม่ใช่สร้างไฟล์ใหม่) — ตั้งชื่อชีทคำตอบให้ตรงกับชื่อในตาราง (`Soil_Results` ฯลฯ)

สำหรับรูปถ่าย: เพิ่มคำถามประเภท "อัปโหลดไฟล์" ในฟอร์ม → Google จะสร้างโฟลเดอร์ Drive
ให้อัตโนมัติ → **ต้องตั้งสิทธิ์แชร์โฟลเดอร์นั้นเป็น "ทุกคนที่มีลิงก์ดูได้" ครั้งเดียว**
ไฟล์ใหม่ที่อัปโหลดจะได้สิทธิ์นี้ต่อเนื่องเอง — dashboard จะแปลงลิงก์ Drive เป็นรูป thumbnail ให้อัตโนมัติ

ข้อมูลจะกรอกผ่าน Form หรือแก้ไข/เพิ่มแถวตรงในชีทเองก็ได้ ใช้ร่วมกันได้ทั้งสองแบบ

## มีอะไรใน v0.1 alpha

- แผนที่ (Leaflet) สลับพื้นหลังได้ 2 แบบ ไม่ต้องมี API key ทั้งคู่: **ภาพถ่ายดาวเทียม (Esri
  World Imagery)** เป็นค่าเริ่มต้น และ **แผนที่ถนน (OpenStreetMap)** — สลับได้ที่มุมขวาบนของแผนที่
- **Preset มาตราส่วนแผนที่** — dropdown เหนือแผนที่ให้กระโดดไปมาตราส่วนมาตรฐาน (1:1,000 ถึง
  1:500,000) ได้ทันที พร้อมตัวเลข "มาตราส่วนปัจจุบัน ≈ 1:N" อัปเดตสดตามการซูม/เลื่อนแผนที่
  (มาตราส่วนจริงอาจคลาดเคลื่อนจาก preset ที่เลือกเล็กน้อย เพราะแผนที่ไทล์ซูมเป็นขั้นละเอียด
  ไม่ใช่ต่อเนื่อง) และมีแถบสเกล (scale bar) มุมล่างซ้ายของแผนที่ให้ดูระยะจริงบนหน้าจอด้วย
- จุดสี เขียว = ผ่านมาตรฐาน, แดง = เกินมาตรฐาน, เทา = ยังไม่มีมาตรฐานเทียบ/ไม่มีข้อมูล
  พร้อม**ป้ายชื่อจุด (site_id) ติดถาวรบนแผนที่**
- เทียบค่าผลตรวจกับชีท `Standards` อัตโนมัติ บอกพารามิเตอร์ที่เกินเป็นตัวๆ — **รองรับมาตรฐาน
  หลายชุดต่อพารามิเตอร์** ผ่านคอลัมน์ `standard_set` (เช่น น้ำผิวดินประเภท 3 vs ประเภท 5) โดย
  แต่ละจุดเลือกใช้ชุดของตัวเองได้ ไม่ระบุ = ใช้ชุดเริ่มต้น
- **Overlay ภาพของตัวเอง**: อัปโหลดรูป (เช่น แผนผังโครงการ) แล้วกำหนดพิกัดมุมภาพ วางทับแผนที่ได้
  พร้อมปรับความโปร่งใส/ซ่อน/ลบทีหลัง
- **นำเข้าไฟล์ KML/KMZ จาก Google Earth Pro**: อ่าน Placemark (จุด/เส้น/รูปหลายเหลี่ยม) และ
  Ground Overlay (ภาพที่เคย overlay ไว้ใน Earth Pro) ได้โดยตรง — ไฟล์ `.kmz` (ที่รวมรูปไว้ในตัว)
  จะนำเข้าได้ครบกว่า `.kml` เปล่า
- **ระยะห่างจากแหล่งกำเนิด**: ใส่จุด type `source` ใน `Sites` (เช่น ตำแหน่งโรงงาน) แล้วระบบจะ
  ลากเส้นประ + คำนวณระยะห่าง (ม./กม.) จากจุดแหล่งกำเนิดไปยังทุกจุดเก็บตัวอย่างในโครงการเดียวกัน
  ให้อัตโนมัติ ทั้งบนแผนที่และในตาราง (ปิด/เปิดเส้นได้ที่ตัวกรอง)
- **พิมพ์รายงาน / บันทึกเป็น PDF** — ปุ่ม "🖨️ พิมพ์รายงาน" เหนือแผนที่ ใส่หัวเรื่องเองได้ (หรือ
  เว้นว่างใช้ค่าเริ่มต้น) ระบบจะรวมภาพแผนที่ปัจจุบัน + สรุปตัวกรองที่ใช้ + ตารางผลตรวจ + รูปถ่าย
  ประกอบ (เฉพาะจุดที่มีรูป) เป็นหน้ารายงานเดียว แล้วเปิดหน้าต่างพิมพ์ของเบราว์เซอร์ให้ — เลือก
  "บันทึกเป็น PDF" ในหน้าต่างพิมพ์เพื่อได้ไฟล์ PDF (ไม่ต้องติดตั้งอะไรเพิ่ม ใช้ฟีเจอร์พิมพ์ของ
  เบราว์เซอร์เอง) ใช้ข้อมูลตามตัวกรองที่เลือกอยู่ตอนกดปุ่มเสมอ
- **ส่งออกแผนที่เป็นรูปภาพ (PNG)** — ปุ่ม "ส่งออกเป็นรูปภาพ" ที่หัวข้อแผนที่ บันทึกสถานะปัจจุบัน
  ของแผนที่ (หมุด/เส้น/overlay ทั้งหมด) เป็นไฟล์ภาพได้เลย — **ข้อควรทราบ**: ถ้าใช้พื้นหลัง
  แผนที่ถนน (OpenStreetMap) การส่งออกอาจไม่สำเร็จเนื่องจากผู้ให้บริการไทล์บางรายไม่อนุญาต
  ดึงภาพข้ามโดเมน (CORS) — พื้นหลังภาพถ่ายดาวเทียม (Esri) ทดสอบแล้วเข้ากันได้ดีกว่า
- **แก้ไขตำแหน่งหมุด/จุดในหน้าเว็บ (local only)** — ปุ่ม "โหมดแก้ไขหมุด" ที่หัวข้อแผนที่ เมื่อเปิดแล้ว:
  ลากหมุดเพื่อย้ายตำแหน่ง, คลิกหมุดเพื่อแก้ไขชื่อ/ประเภท/โครงการ/พิกัด หรือลบจุด, คลิกพื้นที่ว่าง
  บนแผนที่เพื่อเพิ่มจุดใหม่ — การแก้ไขจะ**อยู่ในหน้าเว็บนี้เท่านั้น ไม่ได้เขียนกลับไปที่ Google Sheet
  โดยอัตโนมัติ** กด "ส่งออก Sites.csv" เพื่อดาวน์โหลดตารางจุดที่แก้ไขแล้ว แล้วนำไป copy-paste
  ทับข้อมูลเดิมในชีท `Sites` เอง
- **ตัวกรองจังหวัด/กรณี** — dropdown "จังหวัด" และ "กรณี" ที่แถบตัวกรอง สร้างตัวเลือกอัตโนมัติ
  จากค่าที่มีอยู่จริงในชีท `Sites` (คอลัมน์ `province`, `case_type`) ไม่ต้องตั้งค่าล่วงหน้า
- ตัวกรอง: ประเภทตัวอย่าง, สถานะ, ช่วงวันที่
- ตารางผลตรวจ พร้อม thumbnail รูปถ่าย (คลิกขยาย) และปุ่ม **"คัดลอกตาราง"** — คัดลอกแถวที่กำลัง
  แสดงอยู่ (ตามตัวกรองปัจจุบัน) ไปไว้ที่คลิปบอร์ด วางลง Excel/Google Sheets/Word ได้ทันทีแบบมีคอลัมน์ครบ
- **กราฟแนวโน้มค่าตามเวลา** — เลือกพารามิเตอร์ที่ต้องการดู ระบบจะวาดกราฟเส้นค่าตามวันที่
  แยกสีตามจุด (สูงสุด 8 จุดต่อครั้ง ถ้าตัวกรองเหลือมากกว่านั้นจะแจ้งให้กรองเพิ่ม) พร้อมเส้นประ
  บอกค่ามาตรฐาน — ถ้าจุดที่แสดงใช้คนละชุดมาตรฐานกัน (ผ่านคอลัมน์ `standard_set`) จะไม่วาดเส้น
  มาตรฐานให้ เพราะไม่มีเส้นเดียวที่ถูกต้องสำหรับทุกจุด ใช้ข้อมูลตามตัวกรองด้านบนเสมอ
- Stat tiles สรุปจำนวนจุด/ตัวอย่าง/สัดส่วนผ่าน-ไม่ผ่าน
- รองรับ dark mode อัตโนมัติตามธีมระบบ พร้อมปุ่ม 🌙/☀️ ที่มุมขวาบนไว้สลับเอง (จำค่าไว้ให้ครั้งถัดไป)
- ถ้าเชื่อมชีทไม่สำเร็จ (หรือใช้เวลาโหลดนานเกิน 15 วินาที) ระบบจะแจ้งเตือนและ fallback เป็น
  ข้อมูลตัวอย่างให้ทดสอบต่อได้ ไม่ค้างหน้าจอ
- **รีเฟรชข้อมูลอัตโนมัติทุก 5 นาที** เมื่อเชื่อมกับ Google Sheet จริง (ปิดได้ที่ checkbox ในหัว
  หน้า) — ช่วยให้หลายคนที่เปิดหน้านี้พร้อมกันเห็นข้อมูลที่ใกล้เคียงกันมากขึ้น โดยไม่ต้องกด "โหลดข้อมูล"
  เอง ระบบจะ**หยุดรีเฟรชอัตโนมัติชั่วคราว**ระหว่างที่กำลังอยู่ในโหมดแก้ไขหมุด หรือมีการแก้ไขที่ยัง
  ไม่ได้ export ออกไป กันไม่ให้ข้อมูลที่แก้ไปหาย — มีตัวบอก "อัปเดตล่าสุด HH:MM:SS" ให้ดูด้วยว่า
  ข้อมูลบนจอสดแค่ไหน
  **ข้อควรทราบ**: นี่ช่วยแค่ "เห็นข้อมูลล่าสุดจากชีท" เท่านั้น — การแก้ไขหมุดของแต่ละคนยังคงเป็น
  local-only ตามข้อจำกัดด้านบน ถ้าสองคนแก้ไขหมุดพร้อมกันแล้ว export CSV ทับกัน ยังต้องตกลงกันเอง
  ว่าใครจะเป็นคน apply ทับชีทจริง

**Overlay/KML ที่เพิ่มไว้จะบันทึกอัตโนมัติ** ใน localStorage ของ browser — ปิด/เปิดหน้าเว็บใหม่
แล้วยังอยู่ (ทดสอบแล้ว: เพิ่ม/ลบ/ปรับความโปร่งใส แล้ว reload ข้อมูลตรงกันทุกครั้ง) แต่เป็นการ
บันทึกไว้เฉพาะ**เบราว์เซอร์เครื่องนี้เท่านั้น** ไม่ได้ sync ข้ามเครื่อง/ข้ามคน และถ้าไฟล์ภาพรวมกัน
ใหญ่เกินพื้นที่จัดเก็บของเบราว์เซอร์ (มักอยู่ราว 5-10MB) ระบบจะแจ้งเตือนว่าบันทึกไม่สำเร็จ
(ใช้งานได้ในหน้านั้นต่อไป แต่จะหายเมื่อโหลดหน้าใหม่)

### ข้อจำกัดของ overlay/KML ในเวอร์ชันนี้

- ภาพ overlay ที่หมุนเอียง (rotated ground overlay ใน KML) จะแสดงเป็นกรอบสี่เหลี่ยมตรงตามแนวแกน
  (ประมาณตำแหน่ง) ยังไม่หมุนตามมุมจริง

## ยังไม่มีในเวอร์ชันนี้ (แผนถัดไป)

- ระบบ auth/private สำหรับข้อมูลอ่อนไหว — **ทำไม่ได้จริงในไฟล์ HTML เดี่ยวแบบนี้** ระบบล็อกอิน/
  รหัสผ่านที่เขียนด้วย JavaScript ฝั่ง browser ล้วนๆ (ไม่มี server) สามารถถูกข้ามได้ง่ายๆ ด้วยการ
  เปิด "View Source" — การใส่ระบบแบบนี้จะให้ความรู้สึกปลอดภัยที่เป็นเท็จ จึงตั้งใจไม่ทำ ถ้าข้อมูล
  อ่อนไหวถึงขั้นต้องมีการล็อกอินจริง ต้องมี backend (เช่น Google Apps Script Web App หรือ server
  เล็กๆ ที่ตรวจสอบสิทธิ์ก่อนส่งข้อมูล) ซึ่งเป็นการเปลี่ยนสถาปัตยกรรมที่ใหญ่กว่านี้ — บอกได้ถ้าต้องการ
  ให้ออกแบบแนวทางนี้เพิ่ม

## โครงสร้างไฟล์

```
dashboard/index.html      ตัว dashboard (ไฟล์เดียว เปิดตรงในเบราว์เซอร์ได้)
sheets-template/*.csv     เทมเพลตหัวคอลัมน์ + ตัวอย่างข้อมูล สำหรับสร้าง Google Sheet
```
