กรอกพิกัดโรงงาน + รัศมี แล้วเลือกจังหวัดที่ต้องการค้นหา ระบบจะดึงข้อมูลบ่อบาดาลจาก API สาธารณะของกรมทรัพยากรน้ำบาดาล (DGR) ที่ใช้อยู่เบื้องหลังหน้า download.php (ปุ่ม "json" ในหน้านั้น) มาคำนวณระยะห่างจากพิกัดที่กรอกให้อัตโนมัติ — ไม่ต้องดาวน์โหลดไฟล์เอง

⚠️ เป็นการเรียก API เดียวกับที่เว็บไซต์ DGR ใช้เอง (ไม่ใช่ API ทางการที่มีเอกสารรองรับ) หากทาง DGR เปลี่ยนแปลงระบบ เครื่องมือนี้อาจใช้งานไม่ได้ทันที และข้อมูลจำกัดเฉพาะบ่อ "สถานะใช้การได้ + น้ำจืด" ตามที่ระบบต้นทางกรองไว้

1) พิกัดโรงงาน และรัศมีค้นหา

คัดลอกพิกัดจาก Google Maps มาวางได้เลย (คลิกขวาบนแผนที่ Google Maps → คัดลอกจะได้รูปแบบนี้พอดี)

2) เลือกจังหวัดที่จะค้นหา

ข้อมูลของ DGR แบ่งเก็บเป็นรายจังหวัด ต้องเลือกจังหวัดที่โรงงานตั้งอยู่ก่อน — และถ้าพิกัดอยู่ใกล้ รอยต่อจังหวัด (รัศมีค้นหาอาจครอบคลุมข้ามไปอีกจังหวัด) ให้เลือกจังหวัดข้างเคียงเพิ่มด้วย

รายการบ่อบาดาล

ระยะห่าง (กม.) รหัสบ่อ ตำบล / อำเภอ / จังหวัด ประเภทบ่อ ความลึกเจาะ (ม.) ระดับน้ำหยุดนิ่ง (ม.) พิกัด
ข้อมูลบ่อบาดาลจาก กรมทรัพยากรน้ำบาดาล (DGR) — เครื่องมือนี้เป็นการเรียกใช้ API สาธารณะที่เว็บไซต์ DGR ใช้เอง ไม่ใช่บริการทางการของกรมฯ ผลลัพธ์ใช้เพื่อประกอบการพิจารณาเบื้องต้นเท่านั้น ควรตรวจสอบข้อมูลอย่างเป็นทางการอีกครั้งก่อนใช้อ้างอิง
